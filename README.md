# HushYarn

HushYarn is a distributed, real-time data processing platform utilizing auto-scaling architecture and a high-performance engine.

With HushYarn, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/HushYarn.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

HushYarn is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
